# Note about existing pilot metric files

The files metrics_by_seed.csv, metrics_summary.csv, query_examples.txt and run_summary.txt were generated by the earlier compact prototype under src/ before the reference-aligned model under ml/ was added.

They are retained for development history only. **Do not report these values as results for the reference-aligned implementation.**

The authoritative output for the reference-aligned run is written by scripts/run_reference_model.py to reference_metrics.csv and reference_experiment.json after the real experiment completes. These files should be created from the dataset and model run used for the submission.
